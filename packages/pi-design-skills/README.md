# @giljae/pi-design-skills

UI, motion, and interaction design skills for the [Pi coding agent](https://pi.dev),
from [Emil Kowalski](https://emilkowal.ski)'s
[`emilkowalski/skills`](https://github.com/emilkowalski/skills) (MIT).

Agents routinely ship interfaces that feel "off": `ease-in` on an entrance, a
solid border where a raised shadow belongs, motion that fights the user. These
skills name those mistakes and the fix, distilled from UI work at Vercel and
Linear.

## Install

```bash
pi install npm:@giljae/pi-design-skills
```

Start a new Pi session. The skills load on demand; force one with
`/skill:<name>`.

## What's inside

A full mirror of upstream (20 skills), including:

- `emil-design-eng` — the design-engineering philosophy for UI polish and motion.
- `animate` / `animate-expo` — build an animation from scratch (web / React Native).
- `review-animations` / `improve-animations` — audit motion against a high craft bar.
- `find-animation-opportunities` / `remove-animations` / `choreograph` — where motion helps, hurts, or should coordinate.
- `animation-performance` / `animation-vocabulary` / `apple-design` / `gestures`.
- `pick-ui-library` / `prototype` / `mobile-native` / `break-ui`.
- `learn-taste` / `ask-emil` / `ask-sonner` / `write-swift`.

## Notes

- Skill names are generic (for example `animate`, `prototype`). If another
  installed skill uses the same name, Pi keeps the first and warns.
- `learn-taste` writes `DESIGN.md`; on Pi, project context is `AGENTS.md`.
