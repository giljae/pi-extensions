# @giljae/pi-postgres-skills

PostgreSQL guidance and live database tools for the [Pi coding agent](https://pi.dev).
It vendors Microsoft's [`microsoft/postgres-skills`](https://github.com/microsoft/postgres-skills)
(MIT) and registers its PostgreSQL MCP server.

Three skills, mirrored from upstream:

- `postgresql-best-practices` — PostgreSQL and Azure Database for PostgreSQL / HorizonDB reference guides.
- `pg-graph` — Apache AGE graph workflows: ontology derivation, extraction, openCypher, and graph RAG.
- `migrate-oracle-app` — Oracle-to-PostgreSQL assessment and conversion.

## Install

```bash
pi install npm:@giljae/pi-postgres-skills
```

Start a new Pi session. The package registers `postgres-mcp` through
`@microsoft/postgres-mcp`. The server starts with the session but connects to no
database until you select a connection profile.

## Connect a database

Create a least-privilege, read-only profile. The password is entered at a hidden
prompt and stored in the OS keyring — never in this package, prompts, or shell
history:

```bash
npx -y @microsoft/postgres-mcp connection add my-database "host=... user=... dbname=... sslmode=verify-full" --access-mode ro
npx -y @microsoft/postgres-mcp connection set-password my-database
```

Then ask Pi to connect to `my-database` and inspect the schema.

## What the package changes

- Adds the three skills to Pi.
- Registers the `postgres-mcp` server for the session. Its tools are exposed as
  `mcp__postgres-mcp__<operation>` and default to codemode exposure.
- A user `mcp.json` entry named `postgres-mcp` overrides the registration.

The PostgreSQL role is the effective security boundary. Use a read-only role,
and review every proposed write before approving it.
