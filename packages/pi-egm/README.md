# @giljae/pi-egm

The [Elephant-Goldfish Model](https://egm.dev) (EGM) for the
[Pi coding agent](https://pi.dev): design with an elephant, review with fresh
read-only Goldfish.

An **Elephant** (your Pi session, holding project context) drafts the
specification. **Goldfish** reviewers are fresh child sessions with zero
conversation history that read only the draft and the live source, then
stress-test the design from conflicting perspectives. You make the trade-offs
and approve the spec.

## Install

```bash
pi install npm:@giljae/pi-egm
```

Then run a skill:

```text
/skill:egm-brainstorm Add webhook delivery to this project.
/skill:egm-draft
/skill:egm-review docs/designs/webhooks.md
```

## Skills

`egm-brainstorm`, `egm-draft`, `egm-review`, `egm-review-loop`, `egm-resolve`,
`egm-bootstrap`, `egm-drift-report`.

## How it works on Pi

The package registers the `egm_goldfish` tool. Each reviewer runs in a fresh
headless `pi` process with no extensions, context files, MCP servers, skills,
prompt templates, or persisted session, and with the read-only tools
`read,grep,find,ls` — no `bash`, `edit`, or `write`. The parent writes every
report. See [PI.md](PI.md) for the full mapping.

## Provenance

Skills, personas, document standards, and the `docs/codex.md` and
`docs/claude.md` guides are vendored from
[`google/elephant-goldfish-model`](https://github.com/google/elephant-goldfish-model)
(Apache-2.0, Copyright Google LLC). The only text changes are the Pi routing
line and the `Pi: egm_goldfish` dispatch name. The vendored tree is generated by
`scripts/sync-egm.ts` and recorded in [UPSTREAM.json](UPSTREAM.json); a
scheduled workflow opens a PR when upstream moves.

Not an officially supported Google product.
