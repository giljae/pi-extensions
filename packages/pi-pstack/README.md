# @giljae/pi-pstack

Lauren Tan's [pstack](https://github.com/cursor/plugins/tree/main/pstack)
workflows for the [Pi coding agent](https://pi.dev). pstack is an opinionated
answer to AI slop: if you want to go fast, go deep first. It ships a router
(`poteto-mode`) with 22 playbooks, 24 short engineering principles, and 34
workflow skills so an agent reproduces before it fixes, verifies against the
real artifact before it declares done, and delegates bulk work instead of
flooding the main thread. Vendored (MIT) and adapted for Pi.

## Install

```bash
pi install npm:@giljae/pi-pstack
```

Start a new Pi session, then invoke a skill with `/skill:<name>`, or just start
a task and let `poteto-mode` route it.

## What's inside

- **`poteto-mode`** — the entry point. It matches your task to a playbook
  (investigation, bug fix, perf, feature, refactoring, shipping, overnight run,
  and more) and runs the skills a step needs.
- **24 principles** — one short rule each, from `principle-laziness-protocol`
  and `principle-build-the-lever` to `principle-prove-it-works` and
  `principle-explain-the-number`. `poteto-mode` indexes them and reads the ones
  it applies.
- **34 workflow skills** — including `unslop` (strip AI tells from prose),
  `tdd` (failing test first), `how` (walk a subsystem), `why` (answer from the
  commit and PR record), `technical-writing` (layered doc standard), and
  `no-comments` (strip comments before review).

## How it runs on Pi

pstack is written for Cursor. Every vendored skill carries a one-line note that
points at [`harness/pi.md`](./harness/pi.md), which maps the Cursor surface onto
Pi: `Task` → the `subagent` tool (or the main thread when no subagent tool is
installed), Cursor model slugs → the Pi session model, `.cursor` paths → Pi
paths, and the Cursor-only steps (Bugbot, Automations, cloud agents) to a
one-line `Skipped on Pi:` note.

On a stock Pi with no subagent tool, the delegated steps run in the main thread
and nothing breaks — you still get the playbooks, principles, and verification
discipline. Delegation and per-role model choice are enabled when
[`pi-subagents`](https://www.npmjs.com/package/pi-subagents) is installed; that
integration lands in a later release.

## Notes

- Skill names are generic. If another installed skill uses the same name
  (`prototype`, `swarm`, and so on) Pi keeps the first and warns.
- The `statechart` skill runs a TLA+/TLC toolchain; without Java and TLC
  installed it can only draft and inspect charts.
- Vendored from `cursor/plugins` at a pinned commit and recorded in
  `UPSTREAM.json`. Never hand-edit `skills/` or `agents/`.
