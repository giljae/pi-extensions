# @giljae/pi-blueprint

Animated patent-sheet explainers for the [Pi coding agent](https://pi.dev), from
[`intincrab/blueprint`](https://github.com/intincrab/blueprint) (MIT).

Pi can explain a mechanism in prose; blueprint draws it. Give it a topic and it returns an
animated sheet: parts drawn in one at a time, each numbered with a leader line, each added
because the last one fell short ("but… so…"), with one plain caption per step and tokens
moving along the lines. The finished sheet still explains the idea as a still image.

## Install

```bash
pi install npm:@giljae/pi-blueprint
```

Start a new Pi session.

## Use

```
/blueprint how a cache works
/blueprint why the retry storm took the API down
/blueprint the event loop
```

`/blueprint <topic>` is a prompt template that hands the topic to the `blueprint` skill. You
can also force the skill directly: `/skill:blueprint how a cache works`.

The skill writes a scene (a plain object of parts, lines, and steps), lints it with
`scripts/check.mjs`, renders frames to look at, and then ships it as a `<blueprint-scene>`
element embedded in a page, a standalone HTML file, or an export.

## Playwright (frames and exports)

Linting needs only Node. Rendering frames (`scripts/frames.mjs`) and exporting GIF/PNG/MP4
(`scripts/export.mjs`) need [Playwright](https://playwright.dev). Because the installed
package is read-only, install it in a scratch directory and point the scripts at it with
`NODE_PATH`:

```bash
mkdir -p ~/.cache/pi-blueprint && cd ~/.cache/pi-blueprint
npm i playwright@1.56.1 && npx playwright install chromium

NODE_PATH=~/.cache/pi-blueprint/node_modules node <skill-dir>/scripts/frames.mjs --src scene.js --out /tmp/scene.png
```

GIF and PNG need only Playwright. MP4 uses `ffmpeg` when it is on `PATH`; otherwise Chromium
encodes it with WebCodecs, which covers macOS and Windows with nothing else installed (on
Linux install `ffmpeg`). `--encoder ffmpeg|browser` forces one.

## Exports

```bash
node <skill-dir>/scripts/export.mjs scene.js --format gif
node <skill-dir>/scripts/export.mjs scene.js --format mp4
node <skill-dir>/scripts/export.mjs scene.js --format png
node <skill-dir>/scripts/build.mjs scene.js --out scene.html
```

## Notes

- The frame self-check reads a rendered PNG, so it needs an image-capable model. Without one,
  the skill still lints with `check.mjs` and can export.
- `/blueprint` and the `blueprint` skill are separate namespaces, so they do not collide with
  each other. A user prompt, skill, or command of the same name would; Pi keeps the first
  discovered and warns.
