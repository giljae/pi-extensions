# pi-extensions monorepo and pi-egm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the `giljae/pi-extensions` npm-workspaces monorepo and its first package, `@giljae/pi-egm`, which vendors the pinned EGM v0.1.1 content behind a deterministic sync script and ships a read-only `egm_goldfish` reviewer tool for the Pi coding agent.

**Architecture:** A private root defines the workspaces, TypeScript, vitest, and changesets toolchain. `scripts/sync-egm.ts` clones a pinned EGM tag, copies an allowlisted subset into `packages/pi-egm`, applies two fixed text transforms, and records per-file hashes in `UPSTREAM.json`. The package registers one `egm_goldfish` tool that spawns a fresh, read-only `pi` child per reviewer; a scheduled workflow opens a PR when upstream moves.

**Tech Stack:** Node 22+, npm workspaces, TypeScript (no build step), vitest, `@changesets/cli`, GitHub Actions. Peer/runtime types from `@earendil-works/pi-coding-agent` and `typebox`.

**Spec:** `docs/designs/pi-extensions.md`

## Global Constraints

- npm scope `@giljae`; first package name `@giljae/pi-egm`; tool name `egm_goldfish`.
- Pinned upstream: `https://github.com/google/elephant-goldfish-model`, tag `v0.1.1`, commit `dea7761de06ce5b51c177ebb9bba0469f24af5a4`.
- Reviewer child args are exactly `--no-extensions --no-context-files --no-session --no-mcp --no-skills --no-prompt-templates --tools read,grep,find,ls`. Reviewers never receive `bash`, `edit`, or `write`.
- `packages/pi-egm/{skills,agents,resources,docs}` and `UPSTREAM.json` are generated by `scripts/sync-egm.ts`. Never hand-edit them.
- Transform anchors, exact:
  - pointer line: `In Claude Code or Cowork, read \`${CLAUDE_PLUGIN_ROOT}/docs/claude.md\` first.`
  - inserted after it: `In Pi, read \`../../PI.md\` first.`
  - dispatch enumeration token: `` Codex: `spawn_agent`) `` → `` Codex: `spawn_agent`; Pi: `egm_goldfish`) ``
- No build step: packages publish raw TypeScript. Every `pi` package manifest carries the `pi-package` keyword, `publishConfig.access: "public"`, and a minimal `files` list (runtime only).
- Tests run with `npm test` (vitest). Typecheck with `npm run typecheck` (`tsc --noEmit`).

## Review Focus

1. Upstream rewrites the Claude preamble wording → the sync transform must fail loudly, never skip silently.
2. A reviewer gains a mutation tool (`bash`/`edit`/`write`) → `buildGoldfishArgv` test must pin the exact allowlist.
3. A vendored file is hand-edited → the integrity test must fail on a hash mismatch.
4. `APPEND_SYSTEM.md` reaches a reviewer → live gate; document as a known limit if Pi loads it.
5. A package manifest is missing `pi-package`, `files`, or `publishConfig` → a manifest test must fail before publish.

- [ ] **Step 3: Implement the transforms and the sync runner**

Create `scripts/sync-egm.ts`. Export the two pure functions and `runSync`.
Behavior the tests and Task 3 pin:

- `insertPiPointer(text)`: throw `Error("Claude anchor not found or ambiguous")` unless
  the Claude line appears exactly once; throw `Error("Pi pointer already present")`
  when the Pi line is present; otherwise insert the Pi line on the next line.
- `appendPiDispatchName(text)`: replace the exact token
  `` Codex: `spawn_agent`) `` with `` Codex: `spawn_agent`; Pi: `egm_goldfish`) ``.
  If the token is absent, return the text unchanged; if it appears more than once, throw.
- `runSync({ ref, packageDir, root })`:
  1. `git clone --depth 1 --branch <ref> --single-branch https://github.com/google/elephant-goldfish-model <tmp>`;
  2. `commit = git -C <tmp> rev-parse HEAD`;
  3. copy `skills/**`, `agents/*.md`, `resources/**`, `docs/codex.md`, `docs/claude.md`;
  4. for every `skills/*/SKILL.md`: `insertPiPointer`, then `appendPiDispatchName`;
  5. write `UPSTREAM.json` with `repo`, `ref`, `commit`, `transforms: ["pi-pointer","pi-dispatch-name"]`, and a `files` map of repo-relative path to SHA-256;
  6. remove `<tmp>`; return `{ changed, commit }` where `changed` is false when the computed file hashes equal the previous `UPSTREAM.json`.

- CLI: `tsx scripts/sync-egm.ts [--ref <tag> | --latest] --package <dir> [--check]`. `--latest` selects the highest semver tag from `git ls-remote --tags`. `--check` compares the tree against `UPSTREAM.json` and exits non-zero on any diff without writing.

```ts
import { spawn } from "node:child_process";
import * as fs from "node:fs";
import * as os from "node:os";
import * as path from "node:path";
import { fileURLToPath } from "node:url";
import type { ExtensionAPI } from "@earendil-works/pi-coding-agent";
import { Type } from "typebox";

export const ROLE_TO_PERSONA = {
  "egm-bootstrap-orchestrator": "agents/bootstrap_orchestrator.md",
  "egm-codebase-details": "agents/codebase_details.md",
  "egm-comprehension": "agents/comprehension.md",
  "egm-design": "agents/design_critic.md",
  "egm-implementation-readiness": "agents/implementation_readiness.md",
  "egm-inventive-catalyst": "agents/inventive_catalyst.md",
  "egm-structural": "agents/structural.md",
  "egm-style": "agents/style.md",
  "egm-synthesizer": "agents/synthesizer.md",
  "egm-zoom-out": "agents/zoom_out.md",
} as const;
export type GoldfishRole = keyof typeof ROLE_TO_PERSONA;

export const ISOLATION_ARGS = [
  "--no-extensions", "--no-context-files", "--no-session",
  "--no-mcp", "--no-skills", "--no-prompt-templates",
] as const;
export const READ_ONLY_TOOLS = ["read", "grep", "find", "ls"] as const;

export function buildGoldfishArgv(task: string, extra: string[] = []): string[] {
  return [...ISOLATION_ARGS, "--tools", READ_ONLY_TOOLS.join(","), ...extra, "-p", task];
}

const HERE = path.dirname(fileURLToPath(import.meta.url));
const ROOT = path.resolve(HERE, "..", "..");

function invocation(args: string[]): { command: string; args: string[] } {
  const script = process.argv[1];
  const bunVirtual = script !== undefined &&
    (script.startsWith("/$bunfs/root/") || /^[A-Za-z]:[\\/]~BUN[\\/]root[\\/]/.test(script));
  if (script && !bunVirtual && fs.existsSync(script)) return { command: process.execPath, args: [script, ...args] };
  const execName = path.basename(process.execPath).toLowerCase();
  if (!/^(node|bun)(\.exe)?$/.test(execName)) return { command: process.execPath, args };
  return { command: "pi", args };
}

export default function (pi: ExtensionAPI) {
  pi.registerTool({
    name: "egm_goldfish",
    label: "EGM Goldfish",
    description:
      "Run one EGM Goldfish reviewer in a fresh, read-only context and return its findings as text. The parent writes any report file.",
    parameters: Type.Object({
      role: Type.Union(Object.keys(ROLE_TO_PERSONA).map((r) => Type.Literal(r)), {
        description: "Which EGM persona the reviewer adopts.",
      }),
      target: Type.String({ description: "Absolute path of the document under review." }),
      model: Type.Optional(Type.String({ description: "Optional pi model pattern for the child." })),
      thinking_level: Type.Optional(Type.String({ description: "Optional pi thinking level for the child." })),
    }),
    async execute(_id, params) {
      const rel = ROLE_TO_PERSONA[params.role as GoldfishRole];
      const persona = fs.readFileSync(path.join(ROOT, rel), "utf8");
      const body = persona.split("---").slice(2).join("---").trim();
      const promptFile = path.join(os.tmpdir(), `egm-${params.role}-${process.pid}.md`);
      fs.writeFileSync(promptFile, body);
      const extra: string[] = [];
      if (params.model) extra.push("--model", params.model);
      if (params.thinking_level) extra.push("--thinking", params.thinking_level);
      const task = `Task: review ${params.target} as ${params.role}. Return findings as text.`;
      const args = buildGoldfishArgv(task, [...extra, "--append-system-prompt", promptFile]);
      const inv = invocation(args);
      const output = await new Promise<string>((resolve) => {
        const child = spawn(inv.command, inv.args, { cwd: HERE, stdio: ["ignore", "pipe", "pipe"] });
        let out = ""; let err = "";
        child.stdout.on("data", (d) => (out += d));
        child.stderr.on("data", (d) => (err += d));
        child.on("close", (code) => resolve(code === 0 ? out : `${out}\n${err}`));
      });
      fs.rmSync(promptFile, { force: true });
      return { content: [{ type: "text", text: output.trim() }] };
    },
  });
}
```
